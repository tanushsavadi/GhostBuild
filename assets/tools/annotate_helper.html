annotations.json helper

Runs entirely offline in this page. Pick a photo, drag the CROP box, then place ONE highlight, fill the fields, press "Add view", repeat for where/how/correct, copy the JSON into assets/sources/<guide_id>/annotations.json. Coordinates are pixels of the ORIGINAL photo.

Load a photo.

Crop: drag a box (yellow dashed). Highlight: circle = drag from centre outwards; rect = drag corner to corner; arrow = drag from tail to the tip (tip = what it points at).
